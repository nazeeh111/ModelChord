## Bounded trained-factor repair

Each stage starts from the current accepted static model. Six controlled interventions are trained: each of3 layers × rank1 or2. Insert a zero-effect additive factor B@A; all existing weights and biases are frozen. A begins from a deterministic orthogonal random basis, B at zero. Train factors with Adam lr0.02 for30 full-calibration updates. Each update includes all four domains and exactly the same labeled sources. Deficit weighting uses detached calibration accuracy shortfalls, temperature0.08, softmax and a minimum weight0.1, normalized; this is a differentiable cross-entropy surrogate, not the accuracy constraint itself.

Each proposed factor block has Frobenius norm at most4, projected after each update. A complete30-step trajectory may cross temporary protected-task losses. Only its final disjoint selection checkpoint may be accepted. Reject if the fixed original protected-reference margin fails, any output is nonfinite, or the lexicographic objective (worst nonnegative selection deficit, sum deficits, mean cross entropy) does not improve. Choose the best feasible intervention, preferring lower rank on a complete objective tie. Fold the accepted factor into dense weights. Rejected candidates leave the preceding accepted model byte-equivalent. Up to4 stages, rank sum at most8,24 candidate trajectories,720 training updates total search. A stage cannot silently fine-tune full weights. Initial feasible ordinary models return without correction. Stop after a feasible strengthened planning contract; never continue tuning on new cohort observations.

This is data-assisted repair, not training-free merging. Functional interventions identify locally useful layers under the recorded examples; no global causal interference diagnosis or novelty claim follows. Sum-of-chunk ranks is an upper bound; all final classifier heads count in size.

## Strong matched controls

For each repair, use the same ordinary starting weights, calibration inputs/order/preprocessing, fixed protected-reference margins, selection objective, and number of executed stages. Compare six continuous trajectories with30-update checkpoints per stage. All six trajectories run the declared number of stages, while the best permitted checkpoint is retained, so both total training source accesses and selection-checkpoint ceilings match the repair search exactly on finite runs. A baseline can select an earlier checkpoint. Report actual failed/attempted/completed accesses instead of requested counts on nonfinite runs.

1. Ordinary full-weight joint Adam: lr{0.001,0.006,0.02} × uniform or deficit-weighted loss =6 trajectories. All weights may change, explicitly a conventional training baseline. No teacher calls.
2. Fixed-all-layer low-rank Adam: fixed ranks(3,3,2), total8; uniform loss; lr{0.001,0.003,0.006,0.01,0.02,0.04} =6 trajectories. Global correction norm is bounded by the repair's overall triangle-inequality ceiling (4stages×4=16), avoiding an artificially tighter per-layer cap. The adaptive repair also has a smaller per-new-block trust region. Different parameterization is disclosed; fixed-all-layer comparison does not isolate priority alone.
3. Uniform-loss adaptive-factor ablation: same six layer/rank interventions, optimizer, inputs and rank/stage ceilings, with uniform task weights. Report its actual early stopping cost; it is the cleaner priority ablation, not proof about the other changed controls.
4. No correction is the ordinary parent. Fixed rank, no protection and no-priority controls are registered before confirmation; their budget differences and possible ties are explicit. Protected-gate synthetic tests establish behavior separately from empirical efficacy.

Reference and repair match total labeled training accesses, optimizer-update totals and selection-checkpoint/access ceilings, all with zero teacher calls, whenever complete trajectories execute. Equal counts do not imply equal FLOPs: frozen/factor/full gradients, projection, copying and factor overhead differ. Report whole-search wall time, peak RSS, actual candidate counts and trainable parameter counts; do not claim exact-compute equivalence or superiority from this small architecture. RegMean's prior parent activation calls and expert training remain separate costs, shared by methods using that starting model.
